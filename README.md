The excuse a robot vacuum gives after eating a sock — a three-beat escalation: it ate the sock, the sock's partner filed a missing-person report, and the laundry basket has seized the vacuum's charging cable as evidence.

## Run it

```sh
python3 main.py
```

Writes the one-liner to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
